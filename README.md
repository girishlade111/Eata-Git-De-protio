# Eata Git De Protio — Portfolio

A personal portfolio website for Girish Lade: a dark, single-page showcase built with plain HTML, Tailwind CSS (CDN) and Lucide icons.

## Features

- Single-page portfolio (`index.html`) with smooth scrolling
- Dark theme (GitHub-dark style `#0d1117`) with Inter typography
- Scroll-reveal animations with staggered delays
- Floating profile animation
- Lucide icon set loaded from CDN
- Responsive layout (works on mobile and desktop)

## Tech stack

- HTML5, CSS3
- Tailwind CSS via CDN (`cdn.tailwindcss.com`)
- Lucide icons (`unpkg.com/lucide`)
- No build step — plain static site

## Quick start

No installation needed. Just open the page in a browser:

```bash
# serve locally (optional)
npx serve .
# or
python3 -m http.server 8080
```

Then visit the shown local URL. Alternatively double-click `index.html`.
